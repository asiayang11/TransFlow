# 网页翻译对照 MVP

实现日期：2026-10-09。入口：`/web`；旧版同页 Demo 保留在 `/web/demo`。

## 运行

```bash
npm install
npm run web:install
```

沿用项目 `.env` 中的 `OPENAI_API_KEY`、`OPENAI_MODEL`、`OPENAI_BASE_URL`，需要兼容 Chat Completions 的文本模型。密钥仅由服务端读取。`TRANSFLOW_LLM_MODE=mock` 时明确拒绝生成译文，不会把原文标成已翻译。

在两个终端分别运行：

```bash
npm run web:backend
npm run dev
```

访问 `http://127.0.0.1:5173/web`。网页服务默认监听本机 `8788`；前端通过 Vite 的 `/api/web` 代理连接。PDF 服务仍独立使用 `npm run backend`。网页翻译会将公开网页的待译文本及少量相邻上下文发送给 `.env` 配置的模型服务；搜索输入框的值不作为翻译块发送，搜索结果文本仍可能被翻译。

## 已实现

- 输入 HTTP(S) 公网网址，原文先展示，右侧按语义段落逐步回填译文；七种目标语言，切换语言重新翻译。
- 一个隔离 Chromium 页面执行原站脚本；rrweb 采集 DOM / 样式 / 表单属性变化，两个禁止原站脚本执行的镜像显示相同状态。
- 普通链接、折叠、按钮、标签和文字搜索从任一侧回传同一真实会话；离散操作串行执行并按请求 ID 去重。新窗口链接在当前会话打开。
- 正文按段落统一翻译，链接、强调和行内代码按受控节点结构回填；可见 `title` / `placeholder` / `alt` / `aria-label` 翻译；代码、公式、用户输入和标记为不翻译的区域保留。保留原 DOM 和 CSS，允许译文自然换行。
- 主滚动区、常见嵌套滚动区按节点与段内位置对齐；驱动真实页面滚动以触发懒加载。可关闭滚动联动。50%–200% 同步缩放及 Ctrl/Cmd + 滚轮。
- 原站后退、前进、刷新、SPA 地址更新；动态新增的可见内容增量翻译。译文回填核对文档 epoch、目标语言和原文，避免过期结果覆盖新页面。
- SSE 流有顺序号；断线重连获取完整基线，缺失序号暂停操作并自动重建基线；段落格式失败只保留该段原文，其他段落继续；模型服务故障暂停新批次，点击重试后恢复。模型返回严格校验块 ID 和文本格式，作为文本写入，不执行 HTML。
- 退出工作区释放会话；断开的会话两分钟后回收。最多同时三个会话，每个最多两项模型请求，首段返回前每批最多2段/约1200字符，随后每批最多4段/约2400字符，优先当前视口；同源段落合并请求；最多3000个当前已发现且未隐藏的文本/属性块。会话缓存最多6000项，资源缓存最多64MB。

## 首版边界

公开文章、文档和产品页优先。不同站点仍需实测；反自动化、网络限制、证书错误或验证码可导致无法访问，不自动绕过。

不支持登录态导入、交易、文件上传、任意复杂表单、拖拽编辑器、跨域 iframe、封闭 Shadow DOM、图片中文字、Canvas/WebGL 和音视频翻译。原生下拉菜单和普通文字控件焦点及其样式同步；光标、选区和任意复杂控件焦点不保证同步。WebSocket、Service Worker、下载和多窗口在源会话中关闭；依赖这些能力的站点可能不完整。

翻译请求以语义段落为单位，模型输出必须保持受保护节点、节点数量和顺序；按原有文本节点原子回填，链接和强调结构保留。可变文字允许为空，以处理目标语言中不需要的冠词。尚不重排行内元素、不提供术语表或通用语义质量保证；结构校验不等于语义正确。超过6000字符或80节点的段落保留原文。只处理当前可见的块，折叠内容展开后处理。超大页面、虚拟列表和高频更新页面不作通用保证。

资源沿用实际浏览器响应缓存，未命中的公开图片、字体、样式由公网资源通道获取；不重放网站业务请求。私有或 blob 资源、动态构造样式及特殊字体仍可能无法还原。Canvas 不录制，iframe / 插件区域以 rrweb 阻挡占位显示。样式相同不代表所有节点边界像素一致。

## 访问隔离

这是本机个人 MVP，不是可直接暴露公网的多租户服务。仅绑定 `127.0.0.1`，校验 Host / Origin，写接口要求专用请求头；随机会话地址作为本机会话凭证。

Chromium 经专用 HTTP/CONNECT 代理访问外网：每次连接解析并检查全部 DNS 结果，拒绝本机、内网、链路本地和保留地址，连接固定到已验证 IP。重定向与子资源也必须经过该代理；禁用 loopback 代理绕过、QUIC、非代理 WebRTC 和 Service Worker。独立资源抓取同样逐次校验重定向并固定 IP；保持 TLS 证书验证。

镜像保留 rrweb `allow-same-origin` 沙箱，未开启 `allow-scripts`；去除脚本、内嵌 frame、事件属性和表单提交目标，资源改为会话地址，并注入限制资源/脚本/连接的 CSP。模型 Key、原站 Cookie 不传到工作台或模型输入中。浏览器原站交互本身可能发起写请求；不能把“只支持公开浏览”理解成已经自动识别并拦截所有副作用。

## 验证

```bash
npm run check       # TypeScript、生产构建、请求所有权及网页协议/安全单测
npm run test:web    # 另含真实 Chromium 集成测试；需要安装 Chromium
```

浏览器集成测试使用受控 HTML 与本地模型替身，不依赖真实模型费用或外网网页内容，覆盖记录器注入、原站脚本只执行一次、同操作去重、折叠增量翻译、搜索输入、滚动、导航 epoch 和会话释放。实际模型及站点的手工验证记录见本次验收结果；这两类证据不能互相替代。

## 与设计提案的取舍

沿用“一个真实会话 + 两个 DOM 镜像”，先用 HTTP + SSE 完成闭环，未引入 WebSocket。未建设持久化任务、账户、云浏览器池、术语库和网页导出。`docs/web-translation-design.md` 保留完整方向，其中未出现在本文件的规划不代表已经实现。
