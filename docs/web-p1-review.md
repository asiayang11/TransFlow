## 已完成清单

- [x] 保存上次成功打开的实际网址、目标语言、视口模式、倍率、适应宽度、横向位置和主文档阅读锚点；刷新后自动新建网页会话并定位。
- [x] 桌面网页固定1280 CSS px，避免双栏窄宽度触发原站移动布局；自适应模式跟随面板宽度。适应宽度只缩放镜像，两个面板始终共享相同逻辑视口与倍率；手动放大时支持横向联动。
- [x] 开启“查看段落原文”后，点击任意一侧的段落查看原文、译文和状态；选择时阻止链接/按钮业务动作，关闭查看模式后恢复操作。
- [x] “定位未译段落”按文档顺序循环定位当前已发现的待译、翻译中或失败段落，并打开对照。
- [x] “重译这一段”只清除该段结果及缓存，优先排入队列；其他成功结果保留。正在执行的同段不会重复提交；导航或原文版本变化时拒绝旧操作。
- [x] 扩充自动化回归，包含完整 React 工作区、HTTP/SSE、真实 Chromium 与受控模型；覆盖刷新、语言切换、双侧折叠、前进/后退、横向联动、内容变化降级和资源隔离。

## 恢复规则

位置使用原文元素标识、标签、文本片段与段内偏移，不保存 rrweb 会话节点编号。刷新导致节点编号变化后仍可按内容匹配；旧段落消失时按滚动比例恢复，并明确提示页面内容已变化。初始化期间短时间重复定位以容纳字体/布局变化；真实点击、滚轮和键盘输入立即让用户接管，普通布局滚动不会取消恢复。

离开工作区前保存位置，镜像销毁后不覆盖最后有效记录。没有位置的记录只恢复网址和偏好，不停留在“正在恢复”。以上两种生命周期情况均有回归。

偏好保存在此浏览器的 localStorage，保留最近一次阅读。保存内容不包含翻译快照、Cookie、搜索输入或浏览器会话。刷新重新访问原站、执行翻译，沿用配置的模型服务与计费。跨设备历史、登录状态、嵌套容器独立位置和无限列表深层内容的精确恢复不在本轮范围。

## 验证

```bash
npm run check
npm run test:web
```

21项网页测试与3项原有前端测试，共24项。工作区回归验证同网址重新打开时 rrweb 编号变化，仍恢复原段落；内容更改后走比例降级。单段重试只产生一个请求项且保留所有成功同伴；旧 epoch 请求被拒绝。两会话请求相同资源 URL 返回各自内容，关闭一个会话不影响另一个。

真实 Python About 页面已验证：1280 CSS px 桌面布局在双栏中按53%适应宽度；刷新恢复到同一段内容；实际点击可查看段落原文、译文，定位未译属性文案，并触发单段重译。真实模型的一次重译出现结构校验失败，页面保留原文并显示失败状态，其他译文保持。390 px 窄屏下页面无横向溢出。
