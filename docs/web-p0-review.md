# 网页翻译 P0 验收

日期：2026-10-09。功能入口 `/web`。构建及20项自动测试通过；六个真实公开站点、当前配置的真实模型完成采样，均有源页和目标页内容，DOM 标签结构一致，重放无异常。

## 交付范围

- 段落统一翻译，保留原始行内节点；代码和数值不由模型覆盖。逐段校验和原子回填，过期译文丢弃。
- 首屏小批次优先、重复段落去重/缓存、方舟翻译关闭深度思考；其他服务不添加方舟参数。
- 搜索输入立即同步；IME 候选阶段不触发搜索，确认后去重；文字光标编辑、本地焦点与同步样式、悬停和离开均有回归。
- 滚动锚点跳过固定/吸顶导航，支持 Shadow DOM；源浏览器回传相同语义锚点，页首/页尾强制对齐。屏蔽嵌入内容时保留安全占位尺寸，避免正文位置改变。
- 一段译文结构失败只影响该段；合法同批译文保留，其他批次继续。服务故障暂停新请求，重试恢复。
- 空白、还原、导航、资源、翻译、断线与会话过期状态；重载、重连、重新打开、分别重试资源与翻译。快照重建后交互继续有效。
- 服务端计时、当前视口覆盖、请求/失败、缓存、模型返回用量与可选单价估算。

## 六站采样

## 翻译质量抽样

- MDN 首段的多段文字、链接和 `<details>` / `<summary>` 代码共同进入一次段落翻译，回填后保留代码和链接节点；结构失败不会覆盖原文。
- W3C 的长句、React 中的80%数值、web.dev 的正文与产品名抽样核对，主要含义保留，未发现首轮按碎片翻译造成的断句。
- 术语仍需语言审校。例如 MDN 的 disclosure 仍出现“披露”这种偏直译用词；P0早期试验也曾发现俄语句子部分未译，最终同页抽样已译成中文。结构校验无法判断语义完整性，不将“已回填”解释为语义验收通过。
- 尚未实现术语库、行内元素重排或大规模语义评分；代码、公式、长段落及首版不支持区域的边界见 `web-mvp.md`。

## 交互与恢复证据

- 受控双镜像测试：中文候选阶段0次源搜索，确认后1次；两侧输入值同步；焦点/悬停/离开、SPA地址和标题、真实滚动懒加载、重连基线及快照重建后点击通过。
- 固定导航、嵌入占位、源滚动像素不一致和滚动中重连均有回归；真实 MDN 左右滚动、返回页首及窗口尺寸变化后保持正文联动。
- 真实 MDN：译文侧展开、原文侧收起时两侧 `details.open` 一致；125%缩放两侧一致；点击“重试翻译”后保留已完成译文并继续失败段落。
- 页面390×844时整页 scrollWidth/clientWidth 都为390；1440×900时两侧共享同一源视口宽度。
- 模拟模型超时、401和坏段落：原文保留，服务故障暂停，段落失败隔离，重试可恢复；未知价格不伪报免费用量。
